## 🎯 Descrição do Projeto:

Este projeto reúne os blogs que criei ou mantenho em produção ou desenvolvimento.

Objetivo: praticar tecnologias (ex: Python, C++, etc.), estruturar conteúdo, talvez experimentar publicação dinâmica ou estática.

Visão: tornar-se uma plataforma leve, expansível e fácil de customizar para publicações rápidas, integrando backend/frontend de forma eficiente.

## 🚀 Instalação & Execução:

# clone o repositório
git clone https://github.com/Gabrielli-Rech/Blogs.git
cd Blogs

# crie um ambiente virtual (se for Python)
python3 -m venv venv
source venv/bin/activate   # ou venv\Scripts\activate no Windows

# instale dependências
pip install -r requirements.txt   # se existir

# configure variáveis de ambiente (exemplo)
export FLASK_APP=app.py           # ou outro nome de entrada
export FLASK_ENV=development

# execute localmente
flask run         # ou python app.py
